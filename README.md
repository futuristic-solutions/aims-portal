# AIIMS Health Portal Frontend

A responsive single-page web dashboard for the AIIMS Health Portal built with HTML, Tailwind CSS, and Vanilla JavaScript.

## Features

* **Interactive Navigation:** Tab switching across Dashboard, Appointments, OPD Schedules, Lab Reports, and Emergency Services.
* **Appointment Booking:** Interactive booking form with instant confirmation feedback.
* **Modern UI:** Built with Tailwind CSS, custom glassmorphism effects, and Lucide icons.
* **Emergency Hub:** Quick access to trauma helplines, ambulance services, and direct contact numbers.

## Tech Stack

* **Structure:** HTML5
* **Styling:** Tailwind CSS (via CDN)
* **Icons:** Lucide Icons
* **Logic:** Vanilla JavaScript

## Quick Start

1. Clone or download the project files.
2. Open `index.html` directly in any modern web browser.
